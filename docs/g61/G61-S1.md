## 1. Kart üretimi (cihazda, paketsiz)
- Mevcut yol: `src/lib/shareCard.ts` (react-native-svg `toDataURL` → PNG → expo-file-system → expo-sharing). Kartlar SVG olarak çizilir (metin, halka, makro hücreleri, logo SVG yolu tasarımda var; QR: saf TS QR üretici yaz — paket yok, `src/lib/qr.ts` + test). Fotoğraflı zemin: SVG `<Image>` ile (yerel dosya/URL; toDataURL'de görünmüyorsa LOG + fotoğraflı zemini o kart için gizle).
- 8 kart: öğün, gün özeti, Keşfet gönderisi, profil, tarif, davet (kod büyük + QR), Tabak Röntgeni (eski `PlateXRayShareModal` yerine), hikâye dışa aktarma (katmanlar + alt köşe bağlantı).
## 2. Paylaş sayfası + hedefler
- `ShareSheet` bileşeni: önizleme gerçek kart bileşeninin küçültülmüşü. Hedefler: **Instagram Hikâye / Gönderi** (bu sürümde: görseli galeriye kaydet + Instagram'ı aç — `Linking.openURL('instagram://')`, açılamazsa sistem paylaşımı; doğrudan hikâye API'si sonraki mağaza sürümü — Notes'taki kısıt), **WhatsApp** (`whatsapp://send?text=` metin + bağlantı; görsel için sistem paylaşımı), **X** (`https://x.com/intent/post?text=&url=`), **Bağlantıyı kopyala** (expo-clipboard VARSA; yoksa RN `Share.share` — yeni paket YOK, LOG), **Kaydet** (mevcut medya kütüphanesi izni/paketi varsa; yoksa gizle + LOG), **Diğer** (sistem sayfası).
- Analitik: `share_open`, `share_target` (kart türü, hedef, boyut, zemin).
## 3. Bağlantılar
- Biçimler (Notes, İlter onaylı): `l.eatkcal.com/p/<post>`, `/u/<kullanıcı>`, `/r/<tarif>`, `/i/<kod>`, `/m/<öğün>`, `/d/<gün>`, `/x/<röntgen>`, `/s/<hikâye>`. Uygulama içi derin bağlantılar `linking.ts`'e (mevcut `/p/` `/u/` var; diğerleri eklenir; `/i/<kod>` davet kodunu kayıt/sepet akışına taşır).
- Paylaşılan öğün/gün/röntgen için herkese açık anlık görüntü: migration `share_snapshots(id short, kind, owner, payload jsonb [yalnız Notes'taki izinli alanlar], created_at, revoked_at)` + `create_share_snapshot` / `get_share_snapshot` (anon okuma, iptal edilebilir). Gönderi/profil/tarif mevcut kayıtlardan.
